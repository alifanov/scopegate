### Recommendations

- **`next` 16.2.12 с двумя critical RCE** → `pnpm add -S next@16.3.3`; критерий: `pnpm ls next` печатает 16.3.3, алёрты #197–#200 закрылись. Задача #319.
- **12 GHSA в шести пакетах** → одна правка `pnpm.overrides` + прямых зависимостей (`nodemailer@9.1.1`, `vitest@4.1.11`, `sharp >=0.35.4`, `hono >=4.13.5`, `browserslist >=4.28.7`, `baseline-browser-mapping >=2.11.0`) и один `pnpm install`; критерий: `pnpm install --frozen-lockfile` проходит, CI зелёный. Сведено в одну задачу, чтобы не гонять шесть прогонов CI на self-hosted раннере (#257, #258, #289). Задача #320.
- **Занятие чужого email по открытому инвайту** → `emailVerified: Boolean(invite.email)` в `acceptInvite()`; этого достаточно, чтобы `requireLocalEmailVerified` (дефолт `true` в better-auth) заблокировал неявную линковку. Критерий: пользователь по открытому инвайту получает `emailVerified = false`. Задача #321.
- **Усиление телеметрии на `/api/csp-report`** → лимит тела ~64 КБ, не больше 10 отчётов на запрос, рейт-лимит по IP на существующем счётчике из `src/lib/mcp/api-keys.ts`. Критерий: POST с массивом из 1000 отчётов даёт не больше 10 спанов. Задача #322.

### Проверено, находок нет

Авторизация всех роутов `src/app/api/**` (`withUserAuth` / `withProjectAuth` / `withAdminAuth` / `handleOAuthStart` → `authorizeProject`), SSRF-барьер на почтовых хостах (`resolveMailTarget` вызывается и на подключении, и на каждом MCP-вызове), AES-256-GCM и HMAC подписи OAuth-состояния, утечка секретов через `listOAuthApps`, IDOR в `/api/notifications` и `requireProjectServiceConnection`.
