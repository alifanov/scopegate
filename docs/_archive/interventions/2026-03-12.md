## 5 Recommendations

### 1. Починить PostHog API ключ — Приоритет: **Критический** (новый)
**Метрика**: Все автоматические отчёты сломаны.
**Действие**: PostHog → Settings → Personal API Keys → создать новый ключ → обновить `POSTHOG_PERSONAL_API_KEY` в `.env` и на сервере (Coolify).
**Импакт**: Без ключа невозможно мониторить эффект любых изменений. Это занимает 2 минуты.

### 2. Починить CTA → signup СЕГОДНЯ — Приоритет: **Критический** (повтор, день 9)
**Метрика**: 7 кликов CTA → 0 регистраций. 9 дней без фикса.
**Действие**: CTA кнопка вызывает `landing_cta_clicked`, но не ведёт на `/login`. Проверить onClick/href, добавить `router.push('/login')`. Все 9 регистраций через прямой URL — signup работает, сломан маршрут CTA.
**Импакт**: Перед запуском ЛЮБОГО трафика это ОБЯЗАТЕЛЬНО нужно починить.

### 3. Запустить Google Ads $10-15/день — Приоритет: **Критический** (повтор, день 6)
**Метрика**: DAU = 0 уже 4 дня. WAU обрушился ~60%. GSC impressions = 0 за 3 дня. Органики нет и не будет в ближайшие недели.
**Действие**: Google Ads: «MCP proxy», «AI agent permissions», «AI access control». Добавить UTM-параметры. Даже 5 кликов/день разорвут мёртвую петлю.
**Импакт**: Единственный способ получить трафик в ближайшие 2 недели. Без трафика все остальные фиксы бессмысленны.
