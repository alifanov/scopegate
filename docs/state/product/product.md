# Что это

AI Access Proxy Layer — гейт гранулярных прав для AI-агентов. Владелец один раз подключает внешние сервисы (Google, Meta, LinkedIn, Stripe, Notion, Jira, Slack и ещё ~20) по OAuth, а агенту выдаёт MCP-эндпоинт с ключом `sg_…`, у которого разрешён только явно отмеченный набор действий.

## Кому

Тому, кто пускает AI-агента к рабочим аккаунтам и не готов отдать ему полный OAuth-скоуп: агент получает не токен, а узкий проброс через прокси.

## Что даёт

- **Гранулярность** — право выдаётся на действие, не на сервис.
- **Отзыв в один клик** — перевыпуск ключа эндпоинта не трогает подключение сервиса.
- **Аудит** — каждый вызов инструмента пишется в `AuditLog` (кто, чем, с каким исходом).
- **Токены не покидают систему** — шифруются AES-256-GCM, обновляются сами, при мёртвом токене приходит уведомление «Reconnect required».

## Состояние

Закрытая система: публичная регистрация выключена, вход только по инвайту. Лендинга, тарифов и биллинга нет.
