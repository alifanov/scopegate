существующим rate-limiting для невалидных ключей (30 req/IP/60s в `api-keys.ts`). Ниже порога
для отдельной задачи.

## Hypotheses

- **Двукратный рост объёма трафика (25 719 vs ~12 271/сутки).** Возможные причины: новая
  активность в Search Console tools (появились 2 новых внешних домена в трейсах — mystize.com,
  secscanner.app), либо органический рост использования. Статус: 1 снапшот — недостаточно данных,
  наблюдать в следующих 2-3 ежедневных прогонах, прежде чем заводить задачу.
- Прошлые гипотезы (`linkedin_create_post` latency, `SELECT Project` aggregate) — без новых данных
  за сегодня (инструменты не вызывались), продолжаем наблюдение без изменений статуса.

## Recommendations

1. **Задача #207** (proposed, medium) — включить причину ошибки Google API в исключение `gscFetch()`,
   чтобы 403 (permissions) отличался от временных сбоев.
2. Объём трафика вырос вдвое — не заводить задачу сейчас, проверить тренд в следующих 2-3 снапшотах.
3. Остальные метрики (DB, latency кроме известного inspect_url, интеграции) — в норме, действий не требуется.
