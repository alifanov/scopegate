### Findings

- **DB**: `McpEndpoint.findUnique` (резолв apiKey на каждый MCP-запрос, `src/app/api/mcp/[apiKey]/route.ts:125`) включает `project.teamMembers` с фильтром `role = owner`. Модель `TeamMember` не имеет индекса, начинающегося с `projectId` (только `@@unique([userId, projectId])`) → p99 249ms на горячем пути. Задача #285 (auto-approved, additive index).
- **Errors**: все 11 ошибок за 24ч — ожидаемые `OAuthTokenError` (revoked-коннекты googleAds/searchConsole) и один Threads timeout; не баг, поведение задокументировано.
- **Latency**: `GET /api/mcp/[apiKey]` p99 ~3.5ч — это SSE-стрим с keep-alive пингами каждые 30с (задокументированное поведение, не инцидент). Медленные `mcp.tool` спаны (instagram_create_post 20.7s, threads_publish_thread 15.4s) — сторонние API с polling/media upload, в рамках 30s tool timeout, не расследовались как баг.
- **Integrations**: оба сервиса (`scopegate-selfhost`, `scopegate-cloud`) отдают трейсы без пропусков.

### Recommendations

1. Задача #285: индекс `TeamMember(projectId, role)` → снизить p99 McpEndpoint.findUnique с 249ms до уровня ~35ms.
