### Findings

- Объём на `scopegate-selfhost` −20.0% к 7-дневному среднему — крупнее обычных суточных качелей (−7.2%…+14.9% за последнюю неделю), но сегодня суббота, а прошлая суббота (09-06) уже показывала разнонаправленные скачки (cloud +25.0%, selfhost −7.2%) без выходной закономерности; единичное наблюдение, ниже порога 3 прогонов — не заводил ни задачу, ни гипотезу (падение объёма не чинится кодом).
- `McpEndpoint` lookup на `scopegate-selfhost` — 24.5ms, стабильно ниже 200мс третий снапшот подряд после закрытия H-008 (refuted). Без изменений.
- 2 ошибки на `scopegate-selfhost` — в пределах штатного шума, `error_log_samples` пуст.
- `mcp.tool instagram_create_post` (20.5s) / `threads_publish_thread` (11.8s) — в рамках 25s-бюджета опроса контейнера Meta, задокументировано в CLAUDE.md; не новая находка.
- `POST /api/cron/refresh-tokens` 9.6s / `oauth-fetch googleAds` 5.1s / `youtube_upload_video` 5.6s на `scopegate-selfhost` — в диапазоне обычных значений для фонового рефреша токенов и загрузки видео, не выше порога 2с только за счёт внешних API; не новая находка.
- Боевой (400/401/404) шум на обоих сервисах — подбор MCP API-ключей на `scopegate-cloud` (332+92× 401 на `/api/mcp/[apiKey]`), сканирование ботами (`.well-known/*`, `wp-admin/install.php`, `.env`, `.git/config`); впервые замечены пробы `/.well-known/agent.json` и `/agent-card.json` (32+32× 404 на `scopegate-cloud`) — тот же класс автоматического сканирования, не отдельная находка.

### Recommendations

- `src/components/landing/footer.tsx` → `<h4>` колонок футера заменить на `<h3>` (или на не-заголовочный `<p>` с `font-semibold`) → в дереве заголовков всех 13 страниц нет скачка `2 → 4`.
- `src/components/landing/pricing.tsx` → названия планов с `h3` на `h2` либо добавить `h2` секции → нет скачка `1 → 3` на `/pricing`.
- `/nope-404-test` → на странице нет ни шапки, ни футера, единственный выход — кнопка «Go home»; навигационная часть — вопрос к `check-ux`, тема закрыта #316.
- `public/og-image.png` 1,1 МБ — грузится только краулерами соцсетей, на вес страниц не влияет; пережать заодно с #315, отдельной задачи не стоит.
- Полировка, без задач: цифры-водяные знаки «01 / 02 / 03» в «How it works» дают 1.38:1 — декоративные, шаг полностью назван заголовком рядом; мобильное меню на 390 занимает 527 из 844 px и не блокирует контент под собой — читается как выпадающее, не как оверлей.
