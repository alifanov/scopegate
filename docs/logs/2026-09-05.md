### Recurring

- **Перекрытие FAB** — третий прогон подряд (2026-08-15 #242, 2026-08-22 #259, сегодня #302). Оба прошлых фикса были вертикальным сдвигом одной и той же кнопки: `bottom-5` → `bottom-24` → `bottom-5`. #302 сформулирована как структурный фикс (скрыть на мобильных, ссылку — в футер), чтобы не запускать четвёртый круг.
- **CLS на `/`** — третий прогон подряд (0.076 → #244, 0.314 → #260, сейчас 0.193). Порог < 0.1 не достигнут ни разу; источник каждый раз новый, сейчас — процентное позиционирование декоративных blur-кругов.
- **Дублирующийся заголовок** — второй прогон подряд, но на другой странице: `/pricing` (#261, закрыт) → `/features` (#305). Готовый паттерн `showHeading` из `pricing.tsx:97` не был применён ко второму такому же месту.

Замер контраста в прошлых прогонах давал ложную чистоту: Tailwind v4 отдаёт цвета как `lab()`/`oklch()`, и парсер по `rgb()` их не разбирал, подставляя белый фон по умолчанию. В этом прогоне цвета нормализованы через канвас — отсюда находки, которых «не было» 2026-08-22.

### Recommendations

- `src/app/layout.tsx:71` → `hidden md:flex` + `mailto` в футере → на 320–414 px ни одного пересечения кнопки с текстовыми прямоугольниками (#302).
- `src/components/landing/hero.tsx:63` → `useState(CODE_LINES.length)` и запуск печати только после монтирования → LCP на `/` < 2.5 с, строки `CODE_LINES` есть в HTML-ответе без `invisible` (#303).
- `src/components/landing/hero.tsx:82,84` → фиксированные смещения вместо `top-1/3` / `bottom-1/4` → CLS < 0.1 на 390 и 1440 (#304).
- `src/components/landing/features.tsx:57` → проп `showHeading`, `showHeading={false}` из `features/page.tsx:163` → «The missing permission layer» ровно один раз в DOM (#305).
- `src/components/landing/hero.tsx:203` → `-top-8` → бейдж не пересекается с шапкой терминала (#306).
- `text-slate-600` → `text-slate-400`, `text-violet-600` → `text-violet-400`, корпус юридических страниц `text-slate-500` → `text-slate-400` → ноль узлов ниже 4.5:1 (#307).
- `/integrations` → векторные логотипы вместо эмодзи (#308).
- Полировка, без задач: на `/pricing` между подзаголовком и тумблером Monthly/Annual ~150 px пустоты на 1440; на `/compare/*` левый край таблицы (x=232) не совпадает с левым краем текста hero (x=296); в карточке Free название плана и цена — одно и то же слово «Free».
