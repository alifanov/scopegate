### Ошибки

18 ошибок за 24ч, разбор по трейсам (полное покрытие — сумма сходится с error_count):

| Причина | Кол-во трейсов | Спанов | Статус |
|---|---|---|---|
| `googleAds:searchStream` (customer 9339932590) → 400 | 1 | 3 | 🆕 новое, см. ниже |
| `googleAds:searchStream` (customer 3440027401) → 403 | 2 (07:15:41, 07:15:42 — подряд) | 4 | 🆕 новое, см. ниже |
| `threads_publish` (container ERROR/EXPIRED) | 2 | 6 | 🟢 известное поведение (`waitForContainerReady` бросает на терминальном ERROR/EXPIRED от Meta) |
| `searchConsole/urlInspection/index:inspect` (без статуса) | 2 | 4 | 🟢 известный TimeoutError, см. Recurring Issues |
| `refresh_connection` (cron) | 1 | 1 | 🟢 единичный случай, ниже порога |

**Google Ads 400/403 — новый паттерн, не встречался в предыдущих снапшотах.** `googleAdsQuery()` и
соседние функции в `src/lib/mcp/google-ads.ts` при `!res.ok` отбрасывают тело ответа Google Ads API
и бросают generic-ошибку — тот же класс проблемы, что был у Search Console до задачи #207
(коммит 8a46ed9). Невозможно отличить permissions-проблему (403, например неодобренный developer
token для конкретного customer) от невалидного GAQL-запроса (400) без похода в трейс вручную.
→ **Задача #208** (proposed, medium).

### Объём запросов

35 596 спанов за 24ч — рост третий снапшот подряд (12 381 → 25 719 → 35 596). Вчера рост был
объяснён гипотезой "новая активность Search Console на внешних доменах"; сегодня доменов
mystize.com/secscanner.app в топе ошибок и латентности уже не видно (они появлялись в ошибках,
не в объёме) — рост объёма пока без подтверждённой причины. Два снапшота подряд с ростом
>2x от базового уровня — граница "недостаточно данных" по вчерашней гипотезе пройдена.
См. Hypotheses.

Пробелов в трейсинге не обнаружено.

## Hypotheses

- **Устойчивый рост объёма трафика (12 271 → 25 719 → 35 596/сутки).** Вчерашняя гипотеза
  (новые Search Console домены) не подтвердилась ростом — их следы в ошибках сегодня минимальны,
  а объём вырос ещё сильнее. Требуется явная причина (breakdown по `service-fetch`/`mcp.tool` за
  день или новый клиент/интеграция) — если рост продолжится без объяснения на следующем снапшоте
  (07-30), завести задачу на расследование источника трафика.

## Recommendations

1. **Задача #208** (proposed, medium) — включить причину ошибки Google Ads API в исключение,
   аналогично исправлению для Search Console (#207).
2. Рост трафика 2x+ второй день подряд без подтверждённой причины — не заводить задачу сейчас,
   но следующий снапшот (07-30) должен либо найти причину, либо стать поводом для отдельной задачи
   на расследование.
3. Остальные метрики (DB, latency, интеграции) — в норме, действий не требуется.
