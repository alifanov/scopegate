## 5 Recommendations

### 1. Welcome email через Resend — Priority: **High**

- **Metric**: Signup → Login = 11% (9 signups, 1 login за 30 дней)
- **Action**: Resend уже импортирован в `src/lib/auth.ts` и настроен для magic links. Добавить welcome email в хук `user.created` (Better Auth supports `databaseHooks.user.create.after`). Письмо: "Как подключить первый сервис за 5 минут" с прямой ссылкой на `/projects` + quick-start guide. Дополнительно: re-engagement через 48ч если нет `project_created` события.
- **Impact**: Email nurture поднимает retention с 11% до 30-40% в SaaS MVP сегменте. При 9 существующих пользователях каждый возврат важен; при следующей волне трафика — это удвоит активацию.

### 2. Новый канал трафика — Priority: **High**

- **Metric**: DAU = 0, 5 дней тишины, HN трафик полностью иссяк
- **Action**: Запустить второй канал одновременно по трём направлениям:
  (1) Reddit: r/selfhosted, r/ClaudeAI, r/mcp — продемонстрировать реальный use case с демо GIF
  (2) Twitter/X thread: "I built a permission layer for AI agents" с примером код → MCP endpoint за 60 секунд
  (3) Product Hunt: запланировать полноценный лонч с hunter, teaser posts, email список
- **Impact**: HN дал 14 уников/день на пике. Reddit r/selfhosted (200k+ членов) + Twitter могут дать сопоставимый результат при хорошем демо. Без нового трафика WAU = 0 и нет данных для оптимизации.

### 3. Индексация SEO страниц в Google Search Console — Priority: **High**

- **Metric**: 2/42+ страниц проиндексированы, 0 non-brand organic traffic; 85 impressions/мес (только branded)
- **Action**: Sitemap существует и генерируется в `src/app/sitemap.ts` (включает compare, integrations, glossary, blog). Проблема — Google не сканировал эти страницы. Действия:
  (1) GSC → URL Inspection → вручную запросить индексацию для /compare, /integrations, /glossary, /blog
  (2) Проверить что страницы рендерятся с контентом (не пустые shell-pages без данных)
  (3) Добавить breadcrumb structured data (JSON-LD) на programmatic pages для лучшей crawlability
- **Impact**: 40+ страниц на long-tail запросы ("mcp permission gateway", "google oauth mcp proxy" и т.д.) могут дать 10-100 organic clicks/day через 4-8 недель после индексации.

### 4. Re-engagement кампания для 9 зарегистрированных пользователей — Priority: **Medium**

- **Metric**: 8 из 9 зарегистрированных ни разу не вернулись (88% one-time abandonment)
- **Action**: Использовать Resend для ручной (или скриптованной) отправки personalized email всем 9 пользователям: "Что нового в ScopeGate", список исправлений UX, конкретный call-to-action (создать первый project → получить MCP endpoint). Включить ссылку на demo video или GIF. Это единовременная акция, не автоматизация.
- **Impact**: Даже 2-3 возвращения из 9 = +20-30% к retention, плюс потенциальные отзывы/фидбэк для улучшения продукта.

### 5. Трекинг `project_created` на уровне API route — Priority: **Low**

- **Metric**: `project_created` tracked только client-side в `projects/page.tsx:95`, не в `api/projects/route.ts`
- **Action**: Добавить `captureServerEvent(user.userId, "project_created", { project_name })` в POST handler `src/app/api/projects/route.ts` (после успешного создания в БД). Это сделает трекинг надёжным — client-side event может не сработать при navigate-before-flush.
- **Impact**: Точные данные о числе созданных проектов = возможность измерять activation rate (signup → project_created). Без этого нельзя знать, где именно теряется пользователь в onboarding.
