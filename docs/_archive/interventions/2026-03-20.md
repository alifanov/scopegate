## 5 Recommendations

### 1. Написать logicswarm.com лично — Priority: **Critical**

- **Metric**: Единственный органический пользователь создавший проект (`Atlant1s`, 2026-03-19). Застрял на шаге "Connect a service". Молчание уже >24 часов.
- **Action**: Отправить персональное письмо через Resend от `hello@scopegate.dev`:
  - Тема: "I saw you created Atlant1s — got 5 minutes?"
  - Текст: founder-to-founder: "Увидел что вы создали проект, но не подключили сервис. Что остановило? Могу помочь лично настроить."
  - Вопрос: какой сервис они хотели подключить? Почему остановились?
- **Impact**: Прямой фидбек от первого реального пользователя. Найти root cause блокера на шаге ServiceConnection. Возможный первый реальный activated user.

### 2. Обновить PostHog personal API key — Priority: **High**

- **Metric**: PostHog `phx_...` ключ в `.env` возвращает 401. Без него аналитика слепая — нет pageviews, events, ошибок.
- **Action**: Зайти в eu.posthog.com → Settings → Personal API Keys → создать новый ключ → обновить `POSTHOG_PERSONAL_API_KEY` в production `.env` на Coolify и в локальном `.env`.
- **Impact**: Восстановит все будущие аналитические отчёты. Сейчас единственный источник данных — прямые SQL запросы к БД.

### 3. Реализовать 48h activation drip email — Priority: **High**

- **Metric**: 0 ServiceConnections при 1 органическом `project_created`. Нет механизма автоматического возврата.
- **Action**: Создать launchd plist (согласно CLAUDE.md — не cron, а launchd) или API cron endpoint. Логика: `SELECT u.email, p.name FROM "user" u JOIN "TeamMember" tm ON tm."userId" = u.id JOIN "Project" p ON p.id = tm."projectId" LEFT JOIN "ServiceConnection" sc ON sc."projectId" = p.id WHERE sc.id IS NULL AND p."createdAt" < NOW() - INTERVAL '48 hours' AND p."createdAt" > NOW() - INTERVAL '72 hours'`. Отправить через Resend: "Застряли на подключении сервиса? Вот как за 2 минуты подключить Google Calendar".
- **Impact**: Автоматически вернёт 15-25% пользователей создавших проект но не активировавшихся.

### 4. Запустить Twitter/X thread — Priority: **Medium**

- **Metric**: 7 дней без трафика (с Mar 13). HN дал пик в 14 уников на пике. Нужен второй канал.
- **Action**: Thread от @jetbootsmaker:
  1. "I built a permission layer for AI agents after a security incident (88% of orgs experienced MCP-related breaches last year)"
  2. "The problem: Claude gets full OAuth scopes — but it only needs to read calendar, not manage Gmail"
  3. "ScopeGate gives each agent exactly the permissions it needs. Per-agent scopes, auditable, revokable."
  4. Demo GIF из `public/scopegate-demo.mp4`
  5. Link: scopegate.dev
  Репост в r/ClaudeAI, r/mcp, r/selfhosted.
- **Impact**: HN показал интерес к теме. Twitter + Reddit могут дать ещё 50-200 уников.

### 5. Запросить индексацию SEO страниц в Google Search Console — Priority: **Medium**

- **Metric**: 40+ программатик SEO-страниц (`/compare/`, `/integrations/`, `/glossary/`) не проиндексированы. 0 organic non-brand кликов.
- **Action**: GSC → URL Inspection → "Request indexing" для топ-5 приоритетных страниц: `/compare/scopegate-vs-aws-api-gateway`, `/compare/scopegate-vs-zapier`, `/integrations/google-calendar`, `/glossary/mcp-protocol`, `/glossary/oauth-scopes`. Проверить Sitemaps → все sitemap URLs успешно поданы.
