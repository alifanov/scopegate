## 5 Recommendations

### 1. Добавить UTM-трекинг в код — Приоритет: **Критический** (блокер для платного трафика)
**Метрика**: 100% трафика = unknown source. Ни один визит не атрибутирован.
**Действие**: (a) Парсить `utm_source`, `utm_medium`, `utm_campaign` из URL при первом визите. (b) Сохранять в PostHog как user/event properties. (c) Передавать при регистрации для атрибуции конверсий.
**Импакт**: Без UTM невозможно оценить ROI любого платного канала. Блокер для рекомендации #2.
**Проверка кода**: Подтверждено — в кодовой базе нет обработки utm_* параметров.

### 2. Запустить платный трафик (начать с контент-площадок) — Приоритет: **Критический** (день 13 без трафика)
**Метрика**: DAU = 0 уже 72+ часов. HN-трафик полностью исчерпан. Органика = 1 impression/день.
**Действие**: (a) Reddit/Dev.to/HN comments — бесплатно, таргетировано. (b) Google Ads $10-15/день по ключам "MCP proxy", "AI agent permissions", "MCP security". (c) Обязательно с UTM-метками (после рек. #1).
**Импакт**: Без внешнего трафика невозможно валидировать CTA fix, onboarding UX, и получить новых пользователей. Продукт в мёртвой зоне 72+ часов.

### 3. Настроить welcome email после регистрации — Приоритет: **Высокий**
**Метрика**: 89% зарегистрированных не логинились повторно. 0 product-interior events.

**Импакт**: Email — единственный канал обратной связи с пользователями. Onboarding banner и welcome dialog реализованы, но пользователи не возвращаются.
**Проверка кода**: Подтверждено — Resend настроен только для magic link. Welcome/drip email отсутствуют.

### 4. Request Indexing для SEO-страниц в GSC — Приоритет: **Высокий** (день 9)
