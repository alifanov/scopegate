# UI-компоненты и паттерны

База — shadcn/ui в `src/components/ui`, Tailwind. Собственных токенов сверх темы shadcn нет.

## Примитивы (`src/components/ui`)

`badge` · `button` · `card` · `checkbox` · `dialog` · `dropdown-menu` · `input` · `label` · `separator` · `skeleton` · `sonner` (тосты) · `table` · `tabs`

## Составные (`src/components`)

| Компонент | Роль |
|---|---|
| `breadcrumbs.tsx` | Навигационная цепочка дашборда |
| `confirm-dialog.tsx` | Подтверждение необратимого действия (удаление эндпоинта, перевыпуск ключа) |
| `service-icons.tsx` | Иконки провайдеров |
| `skeletons.tsx` | Заготовки состояния загрузки |
| `admin/` · `project/` · `layout/` | Экранные блоки соответствующих разделов |
| `landing/` | Весь маркетинговый UI (лендинг, `/pricing`, `/features`, блог/глоссарий/сравнения — navbar, hero, pricing, faq, footer и т.д.) |
| `auth/` | UI входа для cloud-режима (`cloud-sign-in.tsx` — Google/magic-link) |

## Паттерны состояний

| Состояние | Как показываем |
|---|---|
| Загрузка | `skeletons.tsx`, не спиннер |
| Пусто | Карточка с одним действием («Подключить сервис», «Создать эндпоинт») |
| Ошибка операции | Тост `sonner`, форма остаётся заполненной |
| Необратимое действие | `confirm-dialog` с явным названием объекта |
| Мёртвое подключение | Бейдж `revoked` + уведомление «Reconnect required» |

## Правила

- Интерактивным элементам явно ставить `cursor-pointer` — Tailwind не даёт его по умолчанию.
- Перед новым произвольным значением (`rounded-[14px]`) проверить `src/` — если такого ещё нет, брать классы темы.
- У shadcn-компонентов проверять базовые классы с брейкпоинт-префиксами (`sm:rounded-lg`) — кастом без парного `sm:` не переопределит.
