## 5 Recommendations

### 1. Провести UX-аудит онбординга после регистрации — Priority: **Critical**

- **Metric**: `project_created` = 0 при 9 signup. Activation rate = 0%.
- **Action**: Зайти в `/projects` от лица нового пользователя и пройти весь путь. Конкретно проверить: (1) что `/projects?welcome=1` показывает onboarding checklist; (2) что кнопка "Create project" видна и работает; (3) что после создания проекта пользователь понимает следующий шаг (добавить endpoint). Также проверить в БД: `SELECT COUNT(*) FROM "Project"` — если проекты есть, но `project_created` = 0, значит сломан PostHog hook на сервере.
- **Impact**: Исправление онбординга = прямой рост activation rate. Даже 2/9 активных пользователей = первый retention signal и фидбек.

### 2. Re-engagement email для 9 зарегистрированных пользователей — Priority: **High**

- **Metric**: 8/9 зарегистрированных не вернулись; 0 создали проект
- **Action**: `SELECT email, "createdAt" FROM "user" ORDER BY "createdAt"` — получить список. Отправить через Resend personalised email: "Попробовали ScopeGate? Вот 3 минуты до первого MCP endpoint". Включить видео/GIF из `public/scopegate-demo.mp4`. CTA: прямая ссылка на `/projects/new`.
- **Impact**: Даже 2-3 возвращения = +20-30% retention. Без этого 9 пользователей потеряны навсегда.

### 3. Запросить индексацию SEO страниц в GSC — Priority: **High**

- **Metric**: 0/40+ программатик страниц в Google Index; 0 non-brand organic кликов
- **Action**: GSC → URL Inspection → запросить индексацию для: `/compare/scopegate-vs-zapier`, `/compare/scopegate-vs-aws-api-gateway`, `/integrations/google-calendar`, `/glossary/mcp-protocol`, `/glossary/oauth-scopes`. Проверить sitemap в GSC → Sitemaps.
- **Impact**: После индексации: 10-100 organic кликов/день через 4-8 недель по целевым запросам.

### 4. Добавить 48h activation drip email — Priority: **Medium**

- **Metric**: Activation rate = 0%; нет механизма возврата пользователей к core action
