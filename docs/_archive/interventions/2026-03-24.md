### 2. Добавить явный `github_cta_clicked` трекинг в CTA кнопки — Priority: **Critical**

- **Metric**: После OSS-пивота `landing_cta_clicked` больше не срабатывает. Мы не знаем сколько людей кликает на GitHub и с каких страниц. Аналитика по главной метрике (`landing_cta_clicked`) стала пустой.
- **Action**: В `hero.tsx`, `cta-section.tsx`, `navbar.tsx` и во всех страницах добавить:
  ```tsx
  import posthog from 'posthog-js'
  // на onClick GitHub кнопок:
  posthog.capture('github_cta_clicked', { source: 'hero' | 'navbar' | 'features' | ... })
  ```
- **Impact**: Восстановить видимость главной воронки. Без этого мы не знаем, работает ли OSS-пивот вообще.
