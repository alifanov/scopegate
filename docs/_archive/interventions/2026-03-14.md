### 2. Исследовать причину post-registration drop-off — Приоритет: **Критический** (день 11)
**Метрика**: 89% drop-off после регистрации, но password auth + авто-логин + redirect на `/projects?welcome=1` уже работают.
**Действие**: (a) Проверить, не ломается ли редирект после signup (DevTools → Network). (b) Добавить PostHog event `projects_page_viewed` на страницу `/projects`. **Импакт**: Auth flow технически корректный. Проблема скорее в value delivery после входа, а не в auth friction.

### 3. Request Indexing для SEO-страниц — Приоритет: **Высокий** (день 7)
