## 5 Recommendations

### 1. Починить воронку CTA → Signup — Priority: **High**

- **Metric**: CTA click → signup = 0% (6 кликов CTA, 0 регистраций через этот путь)
- **Action**: Проверить, куда ведёт CTA с лендинга. Если на /login — изменить на /signup. Убрать friction на странице регистрации (cookie banner перекрывает форму на мобильных, нет loading spinner при сабмите). Добавить PostHog event `signup_form_submitted` и `signup_form_error` для диагностики точки отвала.
- **Impact**: Если починить CTA путь, даже 20% конверсия CTA→signup даст +1-2 регистрации с текущего трафика. Но главное — когда трафик вернётся, воронка будет работать.

### 2. Внедрить welcome email через Resend — Priority: **High**

- **Metric**: Signup → Login = 11% (9 signup, 1 login)
- **Action**: Resend уже в dependencies, но не импортируется нигде. Реализовать: (1) welcome email при регистрации с quick-start guide, (2) re-engagement email через 48ч если нет project_created, (3) win-back через 7 дней если нет активности. Использовать Resend API + очередь через API route.
- **Impact**: Email nurture — стандартный способ поднять retention с 11% до 30-40%. При 9 существующих пользователях каждый возврат критичен.

### 3. Починить индексацию SEO страниц — Priority: **High**

- **Metric**: 2/42+ страниц проиндексированы, 0 non-brand organic traffic
- **Action**: Проверить sitemap.xml (генерируется ли автоматически через Next.js), robots.txt, canonical tags. Убедиться что /blog, /features, /integrations, /compare, /glossary страницы доступны для индексации. Добавить внутренние ссылки между страницами. Отправить URL через GSC URL Inspection для ускорения.
- **Impact**: 40+ страниц контента без индексации — это упущенный organic traffic. Починка может дать 10-50 impressions/day на long-tail запросы.

### 4. Добавить трекинг post-signup activation funnel — Priority: **Medium**

- **Metric**: Нет данных о post-signup воронке (project_created → service_connected → endpoint_created → mcp_request)
- **Action**: Добавить compound event `user_activated` (определение: project_created + endpoint_created + первый mcp_request в течение 24ч). Создать PostHog funnel insight: $pageview → user_registered → project_created → endpoint_created → mcp_request_received. Это покажет, где именно отваливаются пользователи после signup.
- **Impact**: Без этих данных невозможно приоритизировать улучшения. Если 100% отваливается на project_created — проблема в onboarding. Если на mcp_request — проблема в документации/интеграции.

### 5. Сделать элементы onboarding checklist кликабельными — Priority: **Medium**

- **Metric**: Нет direct metric, но checklist — единственный guide после signup
- **Action**: В компоненте getting-started checklist (src/app/(dashboard)/projects/[projectId]/page.tsx) сделать каждый пункт ссылкой/кнопкой: "Create a project" → открывает диалог создания, "Connect a service" → скроллит к services tab, "Get MCP URL" → скроллит к endpoint section. Сейчас пункты — просто текст без интерактивности.
- **Impact**: Уменьшает когнитивную нагрузку post-signup. Пользователь видит что делать и может сразу кликнуть. Это low-effort fix с потенциально высоким влиянием на activation.

## Summary

ScopeGate находится в фазе полной тишины — 4-й день без единого события. HN запуск (3 марта) дал всплеск в 14 уников/день, но трафик полностью иссяк за 10 дней. Из 9 зарегистрировавшихся залогинился только 1 (11%). Воронка лендинга сломана: CTA → signup = 0%. SEO контент (42+ страниц) не индексируется. Email инфраструктура не задействована.

**Приоритет #1**: Починить воронку signup + внедрить email nurture, чтобы существующие и будущие пользователи не терялись на этапе регистрации и активации.
